🦇 Vampire Installation & Guide

1-command 24/7 IP routing, all-ports forwarding, and persistent tunnel manager.

🚀 1-Command Installation
Step 1 — Gateway Setup

Run this command on your Gateway server:

curl -sSL https://iproute.vampirenodes.in | sudo bash -s -- gateway
Step 2 — Node Setup

Run this command on your Node server (using the IP & Token generated by Step 1):

curl -sSL https://iproute.vampirenodes.in | sudo bash -s -- node --server GATEWAY_IP --token SECRET_TOKEN
🔑 SSH Setup — Port 24

Configures SSH on Port 24 with PermitRootLogin yes and PasswordAuthentication yes, prompts to set root password, forwards port 24 automatically, and prints your ready-to-use login command:

sudo vampire setup ssh
Direct SSH Login: After setup, access your server anytime via:
ssh root@GATEWAY_IP -p 24
🌐 Port Forwarding
Option A — Forward ALL Ports (1-65535)

Forwards all TCP & UDP ports across your servers:

sudo vampire add all
Option B — Forward a Specific Port

Forward individual game or application ports:

sudo vampire add <port> [tcp|udp|both]
Examples:
• Minecraft: sudo vampire add 25565
• FiveM: sudo vampire add 30120 tcp
• Palworld / Rust: sudo vampire add 8211 udp
🛡️ 24/7 Disconnect Shield & App Daemonizer

Locks system settings so processes and tunnels never die when SSH disconnects:

sudo vampire 247

Run any game server, website, or bot as a 24/7 background systemd service:

sudo vampire 247 run "java -Xmx4G -jar server.jar nogui"

📋 Vampire CLI Quick Reference
sudo vampire status
Check live tunnel status, active forwarded ports, and watchdog health
sudo vampire setup ssh
Setup SSH on port 24 with root login, password auth, and tunnel routing
sudo vampire add all
Forward all 65,535 TCP and UDP ports
sudo vampire remove <port|all>
Stop forwarding a specific port or remove the all-ports forward rule
sudo vampire page
Start or restart the success confirmation page on Port 9090
sudo vampire logs
View real-time service logs for debugging
