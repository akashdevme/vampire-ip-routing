How to Keep Everything 24/7 Online

Everything you need to know to ensure your routed Public IP and your hosted games/apps never go offline when you close SSH or disconnect from your VPS.

⚡
Why does it go off when closing SSH?
When you close your terminal or SSH window, Linux automatically sends a SIGHUP (Hangup Signal) to any foreground command running in that session. To keep things online 24/7, programs must be run as kernel network interfaces, systemd services, or detached via screen.
1

Whole IP Routing (Recommended — 24/7 Kernel Tunnel)

Route the ENTIRE Public IPv4 (all 65,535 TCP & UDP ports) to your private VPS using kernel-level WireGuard. Because WireGuard runs directly in the Linux kernel as a network interface (wg0), it has zero connection to SSH and stays live 24/7 automatically as long as the VPS is powered on.

All 65,535 Ports Auto-starts on Boot Zero SSH Dependency 25s Keepalive
Step 1 — Run on Public IPv4 VPS (Gateway)
sudo bash wireguard-server.sh

Choose Option 1 (WHOLE IP). It protects SSH port 22 automatically and forwards all other 65,535 ports to your private node.

Step 2 — Run on Private / NAT VPS (Worker)
sudo bash wireguard-client.sh

Enter your Public VPS IP and keys when prompted. The client enables wg-quick@wg0 and keeps the connection alive 24/7.

2

Vampire 24/7 Disconnect Shield (For FRP Users)

If you are using the standard Vampire 1-command installer (vampire.sh), run this one command on your VPS to configure the OS to never terminate your services when SSH disconnects.

Run on either VPS
sudo vampire 247
  • ✔ Enables User Lingering: Background tasks continue running after logout.
  • ✔ Disables KillUserProcesses: Prevents systemd-logind from killing background tasks.
  • ✔ Kernel TCP Keepalive: 60s probe cycles prevent NAT routers and firewalls from dropping idle sessions.
  • ✔ Auto-Healing Watchdog: Checks every 30s and auto-restarts services if any tunnel drops.
3

Running Your Game Server / Web App 24/7

Once your IP tunnel is live 24/7, make sure your game server (Minecraft, FiveM, Palworld) or script doesn't close with SSH:

Option A — One-Command 24/7 Daemonizer (Easiest)

Automatically turns any startup command into an auto-restarting systemd service that boots with your VPS:

sudo vampire 247 run "java -Xmx4G -jar server.jar nogui"
sudo vampire 247 run "./start.sh"

Option B — Using Screen (For Interactive Game Console)

If you want to view your Minecraft / FiveM console and type in-game commands:

1. Install and start a named screen session
sudo apt install screen -y && screen -S myserver
2. Inside the screen, run your server command

Run your server (e.g. java -jar server.jar).

3. Safely detach from the screen

Press Ctrl + A, then press D.
You will see [detached from ...]. You can now close your SSH window!

4. Reattach anytime when you reconnect via SSH
screen -r myserver
